# Citace a zdroje

## Použité zdroje

- Google Fonts – rodiny písem DM Mono, DM Sans a Manrope: https://fonts.google.com/
- W3C Nu Html Checker – validace HTML: https://validator.w3.org/nu/
- W3C CSS Validation Service – validace CSS: https://jigsaw.w3.org/css-validator/

## Prompty k tvorbě projektu

Následující prompty jsou rekonstruované pro dokumentaci projektu:

- „Vytvoř osobní portfolio v češtině pro studenta. Použij moderní tmavý vzhled, výraznou úvodní sekci, přehled projektů, krátké představení a kontaktní část.“
- „Navrhni sémantickou a přístupnou HTML strukturu stránky. Navigaci propojuj s jednotlivými sekcemi pomocí odkazů a přidej smysluplné popisky pro čtečky obrazovky.“
- „Napiš responzivní CSS pro osobní portfolio s decentními barvami, typografií z Google Fonts, kartou projektu a dobře čitelnou patičkou.“
- „Do patičky portfolia přidej odkaz na soubor citace.md v tomto GitHub repozitáři. Otevři odkaz v nové kartě bezpečným způsobem.“
